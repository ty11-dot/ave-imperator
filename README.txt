Ave Imperator - Netlify site with a built-in view counter

Deploy (needs Node.js installed):
  1. Open a terminal in this folder.
  2. npm install
  3. npx netlify-cli deploy --prod
     (first time: it opens your browser to log in, then asks which site - choose your existing Ave Imperator site)

See the count:  https://YOUR-SITE.netlify.app/api/views
The count also shows under the title on the game's opening screen.
